## Topic
My topic will be Flowers that correlate to each zodiac sign. So when it's clicked on or the birthday is typed in, it will bloom the flower that correlates to that zodiac sign, give a short description of why that flower is unique to them, and then play a unique sound that represents the aesthetic/vibe the flower or the environment around it gives.
